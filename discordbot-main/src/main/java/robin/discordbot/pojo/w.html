张雪峰怎么了？考研名师多个账号突遭禁言引热议

近日，知名考研辅导名师张雪峰的多个社交媒体账号突然被禁止关注，这一事件迅速在网络上引发了广泛关注和讨论。包括微博、小红书、抖音和B站等多个主流平台均显示其账号处于“禁止关注”状态，给出的理由多为“违反法律法规或社区公约”。

一位男教师站在黑板前，手指指向写有“人生成功路志愿者第一步”的字样。

事件始末与张雪峰的回应

据报道，9月24日，大量网友发现无法关注张雪峰在各大平台的账号。例如，其微博账号提示“该用户因违反法律法规或《微博社区公约》被禁止关注”。面对突如其来的变故，张雪峰本人向媒体回应称：“禁止关注是账号问题”，随后便挂断了电话，其简短的九字回应引发了更多猜测。

张雪峰面色凝重，背景文字提示其账号被禁止关注。

幕后原因猜想：是“动了蛋糕”还是“账号问题”？

尽管张雪峰本人轻描淡写地归结为“账号问题”，但舆论普遍认为，此事件并非单纯的技术故障。有分析指出，由于张雪峰在考研和高考志愿填报领域的巨大影响力，其言论和建议往往能引导大量学生和家长的选择，这可能触及了某些群体的利益。知乎上便有观点提及，张雪峰的巨大流量可能导致“行业垄断现象”，从而“得罪一大批群体”，包括其同行。

此前，张雪峰曾因在2025届高考志愿填报直播结束时，情绪崩溃、含泪鞠躬，并表示“不管以后发生啥事，希望大家记住，我对得起大家”，这番言论当时便被解读为预示着某种潜在的争议或挑战。

张雪峰站在书架前，手持一张纸，表情专注，似乎在思考。

直播间仍在运行，未来走向引关注

值得注意的是，尽管张雪峰的个人账号遭遇禁言，但据《极目新闻》报道，24日下午，其官方直播间的账号仍在正常运营，主播也仍在进行直播活动。这表明事件可能并非完全的“封杀”，而是针对其个人账号的行为。然而，此事无疑给张雪峰的职业生涯和公众形象带来了不小的冲击。

此次账号被禁止关注事件，再次将张雪峰推向了风口浪尖。其背后的深层原因，究竟是触及了行业敏感地带，还是其他未公开的因素，仍待进一步观察和时间来揭示。
