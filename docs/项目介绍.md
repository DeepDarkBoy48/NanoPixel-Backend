# DiscordAiBot 项目介绍（技术栈与功能）

本项目是一个基于 Java/Spring Boot 的多场景 AI 助手，既能作为 Discord 机器人运行，也提供 WebSocket 聊天室与 HTTP API。项目集成了 LangChain4j 的 Agent / MCP 能力、RAG 向量检索、图片编辑与对象存储、用户体系与鉴权、消息队列驱动的异步处理等功能，适合个人或小团队搭建多模态 AI 助手与知识检索系统。

---

## 项目结构

- `pom.xml`（父工程，Maven 多模块聚合）
- 子模块
  - `discordbot-common`：通用工具与基础能力（JWT、MD5、ThreadLocal 等）
  - `discordbot-main`：业务主模块（Spring Boot 应用、Controller/Service/Listener/配置）

推荐从以下关键包/类了解业务：
- 配置：`discordbot-main/src/main/java/robin/discordbot/config/`（Langchain4j、R2、WebSocket、拦截器、MQ）
- 控制器：`discordbot-main/src/main/java/robin/discordbot/controller/`
- 服务：`discordbot-main/src/main/java/robin/discordbot/service` 及 `impl`
- Discord 监听：`discordbot-main/src/main/java/robin/discordbot/listener/`
- WebSocket：`discordbot-main/src/main/java/robin/discordbot/websocket/WebSocketServer.java`
- 向量/RAG：`EmbedServiceImpl`、`Langchain4j.java`（Chroma/Qwen Embedding）

## 技术栈

- 语言/构建
  - Java 17，Maven 多模块
- 后端框架
  - Spring Boot 3.3.x：Web、WebSocket、Validation、Actuator、Data Redis、AMQP（RabbitMQ）
- 数据 & 缓存
  - MySQL + MyBatis（含 MyBatis-Plus Starter、PageHelper 分页）
  - Redis（会话、令牌与业务缓存）
  - RabbitMQ（PDF 向量化摄取异步化）
- AI 能力（LangChain4j 生态）
  - ChatModel：Google Gemini（`GoogleAiGeminiChatModel`）
  - Embedding：Qwen `text-embedding-v4`（DashScope），以及 AllMiniLm-L6-v2（ONNX，本地）
  - 向量库：Chroma（HTTP 服务端，带元数据过滤）
  - Agent：`AiServices` + `@Tool` 工具调用、ChatMemory（MessageWindow）
  - Agentic（工作流）：`langchain4j-agentic`（示例：`WebAgent`）
  - MCP（Model Context Protocol）：`langchain4j-mcp` 客户端 + 多个 MCP 服务器（Brave Search、YouTube Data 等，需要 Node/npm）
  - 第三方能力：Tavily Web 搜索、X.ai Grok Chat
- 即时通讯
  - Discord Bot：JDA 5.x，ShardManager，多事件监听（频道、论坛贴、按钮交互等）
- 对象存储
  - Cloudflare R2（S3 兼容，AWS SDK v2 实现，带 CDN URL 处理）
- 常用库
  - Hutool、fastjson2、dotenv-java、Jackson JSR310、OkHttp、Lombok、MapStruct

## 核心功能

- Discord 机器人（JDA）
  - 监听频道消息与论坛贴（Thread）
  - “AI 游乐园”频道：
    - `agent` 模式：基于 LangChain4j + Gemini 的工具增强式对话
    - `mcp` 模式：聚合多个 MCP 工具（Brave 搜索、YouTube Data 等）进行工具调用
  - 论坛贴标签驱动搜索（`aisearch`/`aisearchNSFW`）：调用 Tavily 搜索 + Gemini 重写生成中文报告，并自动生成 3 个追问按钮；支持按钮二次搜索
  - 长文本自动分片发送（适配 Discord 2000 字限制）

- Web 聊天室（WebSocket）
  - 端点：`/chat/{sid}`，按 `sid` 维度加载最近历史消息并与 AI 对话
  - 会话记忆：`MessageWindowChatMemory`，按 `sid` 隔离，可清空
  - AGENT 工具：
    - `search`（Tavily）、`getLocalTime`（本地时间）
    - `vectorSearch`（Chroma 向量检索：`fileId` + `userId` 过滤）
    - `clearChatMemory`（清空当前会话记忆）
  - 思考链输出（Gemini Thinking）+ 中文翻译叠加显示

- RAG 向量检索
  - PDF 摄取：RabbitMQ 队列触发（`embed.direct`/`embed.queue`，路由键 `embed.pdf`）
  - 解析：Apache PDFBox；切分：`DocumentSplitters.recursive`
  - 嵌入：Qwen Embedding；存储：Chroma（含 `fileId`/`userId` 元数据）
  - 删除：按元数据过滤批量删除向量

- 媒体库 & 图片编辑
  - 图片编辑：`nanobanana` / `seedream4` 两种模型流程，可配合 Gemini 翻译增强英文编辑指令
  - 上传：Cloudflare R2（原图与处理后图），返回带 CDN 的 WebP 访问地址
  - 资源管理：是否公开、分页获取用户库与公共库、单图详情与原图 URL 查询
  - 调用消耗用户积分（每日重置）

- 用户体系与鉴权
  - 注册/登录：JWT + Redis（存 Token，TTL 控制），拦截器统一鉴权
  - 用户资料：更新资料、头像、密码修改
  - 额度/积分：每日定时重置（`@EnableScheduling` + `@Scheduled`）

- Agent 配置与模型轮换
  - `@S ` 更新系统提示词（新建启用的 Agent 并清空记忆）
  - `@M ` 切换模型名
  - Gemini API Key 轮换工厂（数据库记录 `usage_count`/`last_used_time`），每次调用自动切换并记账

- 安全/工具注意
  - 提供了一个用于演示的 SQL 执行工具（`@Tool sqlExecute`），仅用于受控场景，生产请审慎禁用/加强鉴权

## 重要配置

- Spring Profile
  - `application.yaml`：`spring.profiles.active=dev`
  - `application-dev.yaml` / `application-pro.yaml`：MySQL、Redis、RabbitMQ、Cloudflare R2 等环境配置
- 环境变量（`.env`，位于 `discordbot-main/src/main/resources/.env`）
  - 示例键（请用你自己的密钥替换）：
    ```dotenv
    openaiToken=...
    discordToken=...
    geminiTier1Token=...
    tavilyApiKey=...
    chromaBaseUrl=http://<your-chroma-host>:8000
    qwen=...
    YOUTUBE_API_KEY_S=...   # 若使用 YouTube Data MCP
    ```
- LangChain4j 关键 Bean（`Langchain4j.java`）
  - `chatLanguageModelGeminiFlash()`：Gemini ChatModel（默认 2.5 Flash）
  - `qwenEmbeddingModel()`：Qwen 嵌入模型
  - `chromaEmbeddingStore()`：Chroma 向量库（从 `.env` 读取 baseUrl）

## 运行指引（本地）

前置依赖：
- JDK 17、Maven 3.9+
- MySQL、Redis、RabbitMQ（与 `application-*.yaml` 保持一致）
- Chroma 向量库服务（HTTP 模式）
- Cloudflare R2（或任意 S3 兼容存储）
- Node/npm（如使用 MCP 模式，需 `npx` 启动 MCP 服务器）

步骤：
1) 配置数据库/缓存/MQ 与 `.env` 机密
2) 初始化数据库表（参考各 `Mapper` 中 SQL 与实体命名，例如 `user`、`chat_messages`、`media`、`embed`、`ai_prompts`、`gemini_api_keys` 等）
3) 启动依赖服务（MySQL/Redis/RabbitMQ/Chroma/R2）
4) 运行应用
   - IDE 运行：`robin.discordbot.main`（`@SpringBootApplication`）
   - 命令行：
     ```bash
     mvn -q -DskipTests clean package
     java -jar discordbot-main/target/discordbot-main-0.0.1-SNAPSHOT.jar
     ```
5) 配置 Discord 机器人 Token（`.env` 中 `discordToken`），并在开发者后台打开所需 Gateway Intents

## 主要接口与端点

- WebSocket 聊天：
  - `GET ws://<host>:<port>/chat/{sid}`（打开时推送历史消息；消息驱动调用 AGENT）
  - 清空记忆：`POST /chatroom/clear?sid=...`
- 用户：
  - `POST /user/register`、`POST /user/login`
  - `GET /user/userInfo`、`PUT /user/update`
  - `PATCH /user/updateAvatar`、`PATCH /user/updatePwd`
- 媒体/图片：
  - `POST /ai/imageEdit`（图片编辑，支持多模型）
  - `GET /ai/Userlibrary`、`GET /ai/Alllibrary?sortBy=...`
  - `PUT /ai/media/public`、`GET /ai/media/originurl?mediaId=...`、`GET /ai/media/{mediaId}`
- 其他：
  - `GET /api/translate?text=...`（翻译演示）

## Discord 侧使用说明（示例）

- 在频道 `ai游乐园agent` 发消息触发 AGENT 模式
- 在频道 `ai游乐园mcp` 发消息触发 MCP 模式
- 在论坛 `ai聊天` 的 Thread 内，打上 `aisearch` 标签发起 AI 搜索
- 特殊命令：
  - `@M <modelName>` 切换模型
  - `@S <systemPrompt>` 更新系统提示词（会新建并启用一个 Agent，清空共享记忆）

## 数据安全与最佳实践

- 严禁提交真实密钥：`.env` 与 `application-*.yaml` 中的密钥请仅用于本地测试，生产请走安全的密钥管理（Vault/KMS/环境变量注入等）
- SQL 工具请禁用或加权限：示例中的 `sqlExecute` 仅为演示，存在被误用风险
- 持久化与清理：媒体大文件建议配置生命周期，聊天记录与向量库定期归档/清理
- 压力与配额：MCP/第三方 API 需关注 QPS 与调用配额；Gemini Key 已在代码中实现轮换
